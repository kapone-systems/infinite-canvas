# 远程 ComfyUI：SSH 端口转发

本文是阶段 1–10 全部通过之后的后续计划，不是另一套阶段划分。产品边界仍以 [无限画布开发方案](../无限画布开发方案.md) 为准。进度不写在这里，也不改方案正文。

已经拍板、本文不再讨论的选择：

- 不做「中间翻译」的大模型。ComfyUI 认的是固定 HTTP，不是自然语言。翻译会改错已经填好的提示词、槽位和配方。
- 浏览器仍然不直连 ComfyUI，不持有 SSH 密码或私钥，请求体里也不另给 Comfy 地址。
- 远端机器在后端看起来必须仍是 `127.0.0.1`。办法是后端自己做 SSH 本地端口转发，不是把公网地址填进设置页。
- 工程 JSON 不写 SSH 主机、端口、用户名、密码、私钥、远端 Comfy 端口。这些和现在的 Comfy 地址一样，留在这台电脑上。

本文不把「隧道通了」写成「已经能用远端模型出图」。当前安装包的执行器是替身。隧道只解决连通。真出图是后面单独一刀，而且要对照那台机器上的 ComfyUI 版本核实报文。

---

## 1. 用户能做什么

两种连接，设置页上分两栏，不要合成一个随便填的 URL。

**本机。** 和现在一样。用户自己启动 ComfyUI，填写 `http://127.0.0.1:8188` 这种地址，点「重新检查 ComfyUI」。

**远程。** 用户填写 SSH 主机、SSH 端口、用户名、密码或私钥，以及远端 ComfyUI 在那台机器上的端口。点「连接远程 ComfyUI」。后端在本机找一个空闲端口，执行等价于：

```text
ssh -N -L 127.0.0.1:<本机空闲端口>:127.0.0.1:<远端端口> -p <SSH端口> <用户>@<主机>
```

连接成功后，设置页显示的可用地址是 `http://127.0.0.1:<本机空闲端口>`。预检、运行、取消都只打这个地址。用户不用自己开 PowerShell。

断线时，已有的图还在。再跑会失败，主句用现在的「连不上本机 ComfyUI。请确认它已启动，并且后端配置的地址可达。」不要新造一句把主机名或 IP 暴露成唯一线索。

---

## 2. 不做

- 不把 AutoDL 的公网地址、WebUI-6006 链接、Tailscale 的 `100.x` 地址写成允许的 Comfy 地址。`parseLocalComfyBaseUrl` 继续只接受 `127.0.0.1`、`localhost`、`::1`。
- 不在浏览器里做 SSH。不把私钥放进页面能读到的地方，不把私钥写进 `localStorage` 或工程。
- 不做跳板机、多跳、图形化选密钥文件管理器。第一刀只支持密码，或用户粘贴的 OpenSSH 私钥文本。
- 不改本地并发。仍然是 1。隧道不是第二条本地队列。
- 不在这一刀替换替身执行器。真提交 `/prompt`、上传图片、按 history 取图，单独验收。
- 不把 KSampler、VAE、Checkpoint 画成节点。配方仍是 API 格式填槽。

## 3. 放在哪

| 东西 | 放在哪 | 不放在哪 |
| --- | --- | --- |
| SSH 主机、端口、用户名、远端 Comfy 端口 | `%LOCALAPPDATA%\CanvasApp\ssh-comfy.json`，与 `app.json` 并列 | 工程 JSON、配方、日志 |
| 密码或私钥 | Windows 凭据库。目标名 `CanvasApp:ssh:comfy:account:default` | 工程、`app.json`、`ssh-comfy.json`、壳日志 |
| 本机转发端口和「当前是否连着」 | 后端进程内存。重启后要重新连接 | 工程 |
| 画布实际使用的 Comfy 基址 | 连上之后写入现有的 `comfyBaseUrl`，值只能是 `http://127.0.0.1:<本机端口>` | 远端主机名 |

查询接口只返回「已配置」或「未配置」，以及主机和端口这种非秘密字段。密码框用 `type=password`，保存后清空，不回显。

超过凭据库单条上限的私钥，沿用阶段 9 的 DPAPI 规则，不改成明文文件。

## 4. 接口

浏览器仍然只打本机后端。

```text
GET    /api/app/ssh-comfy
       → { configured: false }
       或 { configured: true, host, port, username, remoteComfyPort, connected: boolean }

PUT    /api/app/ssh-comfy
       { host, port, username, remoteComfyPort, secret }
       secret 是密码或私钥全文。204。响应和后续 GET 都不回显 secret。

DELETE /api/app/ssh-comfy
       断开隧道，删掉凭据和非秘密配置。204。

POST   /api/app/ssh-comfy/connect
       用已保存的凭据重新打开隧道。204，或 400 加主句。

POST   /api/app/ssh-comfy/disconnect
       只关隧道，不删凭据。204。
```

`host` 拒绝空字符串、空格、以及看起来像 URL 的值（带 `://`）。`port` 和 `remoteComfyPort` 是 1–65535 的整数。用户名按 SSH 习惯限制长度，拒绝换行。

实现时用系统自带的 `ssh.exe`（Windows 10 及以上的 OpenSSH 客户端），参数数组，`shell: false`。不要把密码拼进命令行。密码用 `SSH_ASKPASS` 指向一个只在本次连接存活的临时脚本，用完即删；或者用私钥文件，权限收紧，放在应用数据目录而不是工程目录，连接结束可以保留到断开为止，但日志里不能出现私钥正文。

本机监听必须是 `127.0.0.1`，不要是 `0.0.0.0`。远端那一端也写成 `127.0.0.1:<远端端口>`，这样即使用户把 Comfy 只绑在远端回环上也能通，而且不会去扫远端的其他网卡。

连上之后调用现有的 `probeComfyHttp`，目标是 `http://127.0.0.1:<本机端口>/object_info`。2.5 秒内没有 2xx/3xx，就关掉刚打开的隧道，主句仍是「连不上本机 ComfyUI。请确认它已启动，并且后端配置的地址可达。」

## 5. 设置页

在现有「本机 ComfyUI 地址」下面加一节「远程电脑」，不要替换原来的地址栏。

字段：主机、SSH 端口、用户名、远端 ComfyUI 端口、密码或私钥。主按钮「连接远程 ComfyUI」。已经连着时，按钮是「断开」，旁边一行非秘密摘要，例如 `root@主机:端口 → 本机 127.0.0.1:选中的端口`。主机可以用用户填的原文，不要展开成密钥。

失败时节点和设置页只用现有主句。细节可以放在设置页这一节，仍然不能出现密码或私钥的任何片段。

本机地址栏和远程连接可以共存，但同一时刻执行只用一个基址。用户点「连接远程」成功后，基址切换到转发端口。用户改回本机地址并保存后，断开隧道，基址回到用户填的本机地址。不要两个同时提交。

## 6. 分两刀

### 第一刀：隧道

范围：上面的配置、凭据、`ssh -L`、预检打到转发端口、设置页。执行器仍是替身。

验收：

1. 不填远程时，本机地址栏和现在一样。
2. 填一套测试用 SSH（可以是本机 `ssh -D` 不适用；用一台环回 sshd，或开发机转发到本机已有的 Comfy）。连接成功后，`comfyBaseUrl` 是 `http://127.0.0.1:<端口>`，`GET /object_info` 经这条转发到达远端。
3. 工程目录和 `ssh-comfy.json` 搜不到密码或私钥正文。
4. 壳日志、后端访问日志同样搜不到。
5. 关掉远端或杀掉 ssh 进程后，再检查得到「连不上本机 ComfyUI。」已有图片还在，不自动重跑。
6. 浏览器请求里没有 SSH 字段，也没有第二个 Comfy URL。

这一刀通过，只能说「远程电脑能被检查到」。不能说「5090 已经在出图」。

### 第二刀：真执行器

范围：在 `apps/backend/src/execution/comfy/client.ts` 里实现真正的 `ComfyExecutor`：`submit`、`uploadImage`、`wait`、`interrupt`、`inspectPrompt`。安装包和开发启动在用户显式选择「使用本机 ComfyUI」时走它，而不是 `FakeExecutor`。替身保留给测试和 `--fake-executor`。

必须先对照用户那台 ComfyUI 的版本，核实这些公开路径是不是实际字段：

- `GET /object_info`
- `POST /prompt`
- `POST /upload/image`
- `GET /history/:prompt_id`
- 取消用的 interrupt

核实之前，代码注释保持「拟定，未验证」。验收时用那台 5090 上的一个最小 API 配方跑通一张图：提示词进了远端，回来的字节是远端产出的图，不是替身那张小图。本地并发仍然是 1。取消要落到现在已有的三种终态之一，不要新造句子。

没有这第二刀，第一刀不要写进发布说明里说「已支持远程出图」。

## 7. 风险

| 风险 | 处理 |
| --- | --- |
| Windows 没有 `ssh.exe` | 设置页主句说明需要系统可选功能「OpenSSH 客户端」。不要在安装包里再捆绑一套 SSH |
| 密码进了命令行 | 禁止。验收时搜进程命令行和日志 |
| 转发绑到 `0.0.0.0` | 禁止。只绑 `127.0.0.1` |
| 用户把公网 Comfy 地址填进本机地址栏 | 现有解析继续拒绝 |
| 报文和这台 Comfy 不一致 | 第二刀停住，不靠猜字段发版 |
| AutoDL 关机、隧道断了但页面还开着 | 与现在 Comfy 关掉相同：旧图还在，再跑失败 |
