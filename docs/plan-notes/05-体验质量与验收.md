# 体验质量与验收

这份说明把「精美」和「丝滑」写成可以在本机判定通过或不通过的目标。它不选择画布库、不选择状态管理、不选择 ffmpeg 参数，也不给云厂商编请求报文。实现若做不到下面的目标，应换实现，不能把数字改小之后当成通过，也不能单开一个「最后美化」阶段把这些条目收走。

本文里的毫秒、帧率、对比度和时长都是目标，不是已经测过的结果。写作时没有在本机录制帧率，没有跑延迟实验，也没有调用 ComfyUI 或任何云端接口。工作区里能看到 `eval/infinite-canvas-src`，那不是本产品的模块。按已定边界，本文不把它的界面、依赖或表现写成基线。

阶段名字与《无限画布开发方案》草稿中的切片对齐，方便收成一份总方案。若总稿把阶段合并或拆开，验收条目跟着对应切片走，不能挪到单独的美化阶段。

## 1. 谁在什么机器上验收

验收的人是写这个功能的工程师，外加一个没有参加实现的人按本文的演示脚本点一遍。开发机是 Windows。浏览器是本机的 Chrome 或 Edge 当前稳定版，页面由本机后端提供，不是把静态文件直接双击打开。

演示时同时满足这些条件，否则该条记录写成「环境不符合，未观察」，不能写成通过：

- 浏览器标签页在前台，窗口内可见区域至少 1280×720 CSS 像素。
- 笔记本插电。系统没有把浏览器限制成后台节流。演示者不要同时播放全屏视频。
- 用鼠标完成拖拽类脚本。触控板只用于单独写明的平移脚本。
- 阶段 B 以后使用本文规定的夹具场景，不用手边随便堆出来、别人无法复现的图。

夹具是开发构建里的验收场景，不是面向最终用户的模板画廊。正式构建不出现「加载 1000 个测试节点」这种入口。夹具只造节点、边和占位媒体，不内嵌真实密钥，不内嵌大段二进制。占位图用小文件，按内容哈希存放，工程里只写正斜杠相对路径。

夹具至少四个：

| 夹具名 | 内容 | 用来看什么 |
| --- | --- | --- |
| 空 | 已打开工程，零个节点 | 空状态、焦点、失败文案 |
| 二十 | 20 个节点，近景，其中图片节点带小缩略图 | 跟手、连线、撤销、输入法 |
| 一百 | 100 个节点，近景，图片节点带缩略图，含一组连线 | 拖拽帧率、选择、过期徽章 |
| 一千远 | 1000 个节点，视口缩到节点只应显示为色块 | 远景不得解码原图或原片 |

一百和一千的布局要能重复生成：相同种子得到相同坐标。这样两次演示看的是同一张图。

## 2. 通过怎么记

每一条演示只有三种记录：通过、不通过、未观察。未观察不算通过。不通过不能写成「手感还可以」。

延迟和帧率必须有读数才允许记通过。读数来自下面两种办法之一，两种都还没有实现，所以现在没有任何一条可以记通过：

1. 开发构建里的验收叠层。默认关闭。快捷键只在开发构建有效，正式构建没有这个叠层。打开后显示两样东西：最近一次指针按下到选中描边出现的毫秒数；当前这次拖拽里帧间隔超过 32 毫秒的次数。叠层用等宽数字，不参加布局，不挡住节点热区。
2. 若叠层还没做，阶段 B 的帧率条就不能记通过。可以用 60 帧每秒的屏幕录像逐帧看，作为临时办法，但记录里要写明用的是录像而不是叠层。禁止只凭肉眼填通过。

浏览器的 Performance 面板可以当作辅助。它不是产品功能，本文不规定面板里的私有字段名。

一次失败不允许当场把目标改小。若演示机是没有 GPU 的远程桌面，这条环境不在本文的假设里，记录写成未观察，并单独决定要不要为远程桌面另定目标。那个决定不在演示当刻偷偷完成。

阶段完成要同时满足三件事：该阶段每一条演示都有记录；预算表里从该阶段开始生效的行，都至少观察过一次；视觉最低线没有退回成浏览器默认控件。观察可以得出不通过。空白不能算完成。

## 3. 体验层要记住的字段

下面是界面必须能表达的状态，不是渲染库的选型，也不是执行层的 HTTP 草案。执行层可以换字段名，但少任何一项，对应的验收就无法判断。总方案里要有一张映射，把体验层名字对到产品领域的状态机上。映射时可以改名，不能删掉用户能看见的区别。

节点在画布上的呈现：

- `nodeId`：稳定标识。刷新后还是同一个节点。
- `kind`：`text`、`image`、`video`、`audio`、`generation` 之一。生成节点还要有能力标识，例如文生图、图生图、图生视频。能力标识是产品语言，不是 ComfyUI 的类名。
- `freshness`：`fresh` 或 `stale`。过期时还有 `staleReason`，第一版至少能表示「上游改过」。
- `resultState`：`empty`、`ready`、`preview-pending`、`missing-file`。视频在封面还没好时是 `preview-pending`，不是 `empty`。
- `variantCount` 和 `activeVariantId`。变体还在节点内部时，画布上的节点个数不增加。
- `task`：没有在跑的任务就是空。不要用「进度 0%」表示没有任务。

任务呈现，挂在节点上，同时可以出现在不挡画布的任务条里：

- `taskId`：刷新页面后用来重新挂上同一次任务。
- `scope`：`node`（运行此节点）、`downstream`（运行下游）、`selection`（运行选中部分）。
- `status`：`submitting`、`queued`、`running`、`cancelling`、`succeeded`、`failed`、`cancelled`、`cancel-lost-race`、`unknown-after-restart`。
- `queueKind`：`local`、`cloud` 或无。本地和云端不要折成同一个百分比。
- `ahead`：本地队列前面还有几个。不知道就是空，不要写成 0 假装已经开始。
- `progressMode`：`none`、`indeterminate`、`steps`、`ratio`。
- `progressSource`：只有执行器明确给出比例时才是 `executor`。没有这个来源，禁止显示百分比。
- `stepsDone`、`stepsTotal`、`stepLabel`：仅 `steps` 使用。
- `ratio`：0 到 1，仅 `ratio` 且来源是执行器时使用。
- `elapsedMs`：从进入 `running` 起算。排队时间另算，不要把排队伪装成正在生成。
- `lastHeartbeatAt`：云端轮询最后一次有回应的时间。本地任务可以没有。
- `userMessage`：给用户的短句，来自下面的文案表，不是异常栈。
- `failure`：失败时才有，结构见下。

失败呈现：

- `code`：稳定错误码，界面上用小号字显示，供复制。
- `title`：主句，不超过 28 个汉字。
- `detail`：次句，说明现在能做什么。
- `technical`：折叠里的技术信息。可以有本机服务返回的短原因。不得含密钥、密钥片段、完整请求报文。不得把用户主目录当成唯一信息。
- `actions`：有限按钮。允许的动作是重试、取消、把焦点送到槽、去填写密钥、复制错误码、关闭、只重跑失败项、仍然用当前上游结果运行。没有的动作不要画成灰按钮。
- `slotId`：缺槽或角色不对时指向那个槽。

槽的呈现：

- `slotId`、从 1 开始的 `index`、`role`、`required`、`filled`、`sourceNodeId`。
- `role` 用已定边界里的角色：提示词、参考图、首帧、尾帧、风格参考、角色参考、遮罩、音频参考。
- 槽上的错误只有两类：必填为空、连进来的角色不对。

空状态：

- `emptyId`、`title`、`detail`、主按钮和次按钮。
- 同一屏只有一个主空状态。没有节点时，中央空状态负责说话。此时不要再在侧栏放一段意思相同的话。

界面上要逐步加上这些属性，供以后的测试挂钩。现在不写测试代码。没有对应界面时不要提前造假属性。

- 阶段 A：`data-empty`。
- 阶段 B：`data-node-id`。开发叠层的读数用独立区域，不要塞进节点。
- 阶段 C：`data-slot-role`、`data-slot-index`、`data-freshness`。
- 阶段 D：`data-task-status`、`data-progress-mode`。
- 阶段 E：`data-result-state`。
- 阶段 F：视频节点加 `data-playback="poster"`。验收时页面上不应出现指向原片文件的 `video` 元素。

## 4. 任务状态：用户看见什么

产品领域会定正式状态机。下面是体验上必须能分辨的状态。两个状态若用户看起来一样，就当成没做。

| 状态 | 用户看见的主句 | 节点上还有什么 | 画布还能否平移 |
| --- | --- | --- | --- |
| 无任务，且没有结果 | 按节点种类显示空占位，见空状态表 | 没有进度环 | 能 |
| 无任务，输入已齐，没有结果 | 不额外喊话。运行按钮可用 | 没有「0%」 | 能 |
| 无任务，已有结果，未过期 | 不额外喊话 | 结果或封面留在节点里 | 能 |
| 过期 | 上游改过，结果可能对不上 | 旧结果留着，徽章是「过期」 | 能 |
| 提交中 | 正在交给本机队列 | 运行按钮变成取消 | 能 |
| 排队 | 前面还有 N 个本地任务 | 不定进度，没有百分比 | 能 |
| 运行中，无比例 | 正在生成，已用时 m:ss | 不定进度 | 能 |
| 运行中，有步骤 | 正在生成（done/total），已用时 m:ss | 步骤来自执行器 | 能 |
| 运行中，有比例 | 正在生成 p%，已用时 m:ss | 只有 `progressSource=executor` 才允许 | 能 |
| 取消中 | 正在取消 | 取消按钮不可连点 | 能 |
| 已取消 | 已取消，没有新结果 | 旧的成功结果若本来就有，仍留着 | 能 |
| 取消晚了 | 来不及取消，结果已经完成 | 新结果按成功显示 | 能 |
| 失败 | 见失败文案表的主句 | 图标加文字，不只靠红框 | 能 |
| 重启后不确定 | 本机服务重启过，这个任务的结果不确定 | 不再转圈 | 能 |
| 云端久无回应 | 云端还在处理，上次有回应是 N 秒前 | 不把百分比往前爬 | 能 |

禁止这些转移。验收时如果出现，直接不通过：

- 上游一改，下游自己进入提交中、排队或运行中。上游修改只把下游标成过期。
- 失败之后节点变成空白，主句消失，只在控制台留错误。
- 取消中超过 10 秒目标仍停在「正在取消」，且没有落到「已取消」「来不及取消」或「结果不确定」之一。
- 刷新页面后，任务库里已经结束的任务仍永远转圈。
- 用一个假的百分比填满等待时间。百分比不是动画。

本地并发是 1，队列交给 ComfyUI 自己的队列。所以第二个本地任务的诚实表现就是排队，并写明前面还有几个。云端并发不占用这一个本地名额。两边同时存在时，任务条分成「本机」和「云端」两段，不要合成一根总进度。

运行三个动作的呈现：

- 运行此节点：只让这个节点进入提交中。它的下游若会因此过期，在这个节点成功之后才标过期，不自动接着跑。
- 运行下游：下游里真正要跑的节点依次进入提交中。已经是新结果、且上游没变的节点不要闪一下进度。
- 运行选中部分：每个被选中的节点各自有状态。有的可以在排队，有的可以已经失败。汇总句单独出现，不替代节点自己的句子。

一批里的汇总句是「{total} 个里有 {failed} 个失败」。成功的节点保持成功。失败的节点保留自己的主句。汇总上的主动作是「只重跑失败的」。不要把整批都画成失败，也不要只弹一个三秒就消失的提示。

## 5. 贯穿全程的性能与动效预算表

下表是一份预算，不是测量记录。单位写在目标列里。某一行的「生效」阶段还没到，就不拿它卡前面的阶段。生效之后，该行就是通过条件的一部分。

场景一栏里的「二十」「一百」「一千远」就是第 1 节的夹具。

| 编号 | 类别 | 目标 | 场景 | 生效 | 本机怎么看 | 达不到时用户感受到什么 |
| --- | --- | --- | --- | --- | --- | --- |
| P1 | 输入 | 指针按下到选中描边出现，目标 ≤ 50 毫秒 | 一百，近景 | B | 开发叠层的毫秒读数 | 点了却像没点上 |
| P2 | 输入 | 拖节点时，节点相对指针的滞后目标 ≤ 1 帧。按 60 赫兹算，1 帧约 16.7 毫秒 | 二十 | B | 叠层或 60 帧录像 | 节点在追指针，而不是粘在指针上 |
| P3 | 帧率 | 平移、拖节点、拖连线各 3 秒，帧间隔目标不超过 32 毫秒，平均目标 60 帧每秒 | 二十，近景，带缩略图 | B | 叠层里超过 32 毫秒的次数应为 0 | 拖动画布时一顿一顿 |
| P4 | 帧率 | 同上三种手势各 3 秒，超过 32 毫秒的帧目标为 0，平均目标不低于 55 帧每秒 | 一百，近景，带缩略图 | B | 同上 | 一多起来就不能摆布 |
| P5 | 帧率 | 平移 3 秒，平均目标不低于 30 帧每秒。视口内只画色块和标签 | 一千远 | B | 叠层或录像；同时确认没有去解码原图 | 缩小后反而更卡 |
| P6 | 帧率 | 视口里带缩略图的节点目标不超过 40 个。再多就对视口边缘降成色块，而不是把帧率掉到个位数 | 从一百缩放到能看见更多节点时 | B | 数视口内仍在解码缩略图的节点 | 为了看全景，机器先风扇后死机 |

| P8 | 输入 | 文本节点里按键到字符出现，目标 ≤ 50 毫秒。中文输入法组合过程不产生撤销步骤，也不缩放画布 | 二十，文本节点 | B | 输入法组字；撤销一步应撤掉整段已上屏文字 | 打字丢字，或撤销变成逐拼音 |
| P9 | 输入 | 连接桩热区目标至少 24×24 CSS 像素。视觉圆点可以更小 | 二十，含 150% 系统缩放 | B | 用布局检查器看热区，不是看圆点像素 | 线很难拉中 |
| P10 | 进度 | 点击运行后，目标 ≤ 100 毫秒，按钮变成可取消，节点出现「正在交给本机队列」 | 一次文生图 | D | 叠层或可重复的计时 | 点了运行像没反应 |
| P11 | 进度 | 本地第二个任务目标 ≤ 300 毫秒内显示「前面还有 N 个本地任务」。N 未知就保持提交中，不显示百分比 | 本地并发已被第一单占住 | D | 连续点两个节点 | 两单看起来都在同时狂跑 |

| P17 | 过期 | 上游文本每改一个已上屏字符，下游徽章目标 ≤ 100 毫秒出现。期间没有网络请求，也没有新任务 | 文本连到一张已有图 | C | 断网改一个字 | 改了提示词，图还装着是新的 |
| P18 | 动效 | 手势跟随的对象不补间追指针。松手后的惯性默认不做。若做，时长目标 ≤ 280 毫秒，新的指针按下立刻打断 | 拖节点 | B | 半途按下 | 节点不听手 |
| P19 | 动效 | 状态颜色过渡目标 160 毫秒，且不移动节点坐标 | 过期、成功、失败 | C 起过期，D 起成功失败 | 看节点有没有被挤开 | 结果出来时整张图在跳 |
| P20 | 动效 | 缩略图淡入目标 180 毫秒。拖拽一开始就跳到终态，不再淡 | 新结果出现 | E | 出图时马上拖动画布 | 出图动画把拖拽拖死 |
| P21 | 动效 | 面板或变体条展开目标 ≤ 200 毫秒，只影响该节点。做不到便宜的高度动画就瞬间展开 | 打开变体条 | C | 一百节点时展开一条 | 展开一条，整图重排 |
| P22 | 动效 | 角色不对时，线回到原处，目标 ≤ 180 毫秒，并出现角色错误主句 | 把提示词拖进参考图槽 | C | 看回弹和句子 | 线粘在错误的槽上 |
| P23 | 动效 | 任何不接收指针的动画，时长目标 ≤ 400 毫秒。超过的动画禁止 | 全程 | A 起 | 操作时界面仍吃点击 | 看完动画才能继续 |
| P24 | 动效 | 系统开启「减少动态效果」时，P19 到 P22 的时长目标为 0。成功、失败、过期仍靠图标加文字分辨 | 系统设置打开减少动态效果 | A 起文字，C 起状态 | 打开系统设置后重做对应演示 | 关了动画就不知道成败 |
| P25 | 启动 | 后端已经在跑时，从浏览器发出打开工程到空状态可见，目标 ≤ 1 秒 | 空夹具 | A | 刷新计时 | 打开工程先看白屏 |
| P26 | 启动 | 不知道后端死活时，加载圈停留目标 ≤ 5 秒，然后换成「本机服务没连上」 | 后端关掉 | A | 关后端再刷新 | 无限加载 |
| P27 | 视觉 | 正文与背景对比度目标 ≥ 4.5:1。状态不只靠颜色 | 空夹具和失败节点 | A 起 | 用开发者工具读色值再算，本文没有现成测量值 | 灰字看不清；色盲分不清成败 |
| P28 | 视频 | 平移期间画布上目标为 0 个正在播放的原片。节点上是封面。代理没好时主句是「正在准备预览」 | 一个图生视频节点加一百夹具 | F | 检查 DOM 里没有播原片的 `video` | 一拖画布就卡，风扇响起 |
| P29 | 视频 | 等待代理或封面时，平移仍要满足当前节点规模对应的 P3 或 P4 | 代理未完成 | F | 同 P4 的看法 | 为了等预览，整张画布不能动 |
| P30 | 恢复 | 云端超过 15 秒没有新的回应，主句改成「云端还在处理，上次有回应是 N 秒前」。百分比不得自行增加 | 云端任务 | H | 让执行器暂停心跳，本文不规定厂商报文 | 像死机，或进度条在空转 |
| P31 | 展示 | 同时展开的运行明细目标不超过 8 条。更多时折叠成「另有 N 个在运行」，明细不盖住画布 | 云端并发加上一条本地 | H | 造 9 个云端假任务 | 进度卡片把画布盖死 |
| P32 | 输入 | 手势进行中，主线程不做整份工程落盘、不做大文件哈希、不等待网络、不跑 ffmpeg | 拖节点时 | B 起约束，E 起有真实落盘 | 拖拽时看主线程长任务。这是实现约束，不是已测火焰图 | 一拖就卡一下 |

P6 的「40 个」和 P31 的「8 条」都是展示预算目标，用来防止界面把自己拖死。它们不是模型并发上限，也不是云厂商配额。本地执行并发仍是 1。云端真正能并发几个，由执行领域决定，体验只要求超额以后收成一句汇总。

## 6. 输入与手势：怎样算跟手

画布领域决定具体手势由哪个库实现。体验只规定结果。这些结果从阶段 B 起就是验收，不是装饰。

平移和缩放必须把浏览器的过度滚动 containment 住。触控板双指滑动平移画布时，目标是不触发浏览器后退。光标在文本节点里时，滚轮滚动文字，不缩放画布。光标在空白或节点非文本区域时，才把滚轮交给画布。本文不规定是滚轮平移还是按住空格平移，但两种操作不能抢文本插入符。缩放的锚点是光标所在的那个画布点，见 P7。

拖节点是一个手势、一步撤销。拖的过程中每移动一像素都不记撤销。松手后 Ctrl+Z 回到手势开始前的位置，画面目标在下一帧更新，不允许先白一下。重做把节点放回松手处。框选同样：框的过程可以跟手，松手后「已选 N 个」这句的出现目标 ≤ 50 毫秒。N 的句子放在不挡画布的状态条上。

连线拖拽时，橡皮筋每帧更新，预算走 P3 和 P4。松手在非法位置，线回到起点，不留下半截线。松手在合法的槽上，槽的序号立刻可见。从变体条把一个结果拖出来时，跟手预算与拖节点相同。松手仍在变体条内，不新增节点，条里原来的选中不变。松手在画布空白处，才变成新节点。新节点出现时，其他节点的坐标不变。

文本节点必须吃得住 Windows 中文输入法。组字窗口显示在插入符附近，不跑到页面左上角。组字过程中画布不平移、不缩放、不新建节点。上屏之前按 Escape，取消的是组字，不是删除节点。节点获得焦点时要有可见焦点环，不只靠浏览器默认的细线，而且焦点环对比度目标 ≥ 3:1。

分组从阶段 B 就有手感要求：拖动组时，组成员一起跟手，预算仍是 P3 或 P4，不能变成「组在动、成员下一秒跳过来」。组的标题若被截断，用省略号，悬停或选中时能看见全名。不要为了全名把组撑到视口外。

命中的优先顺序要稳定，否则同一下点击每次选中的东西不一样，延迟读数也没有意义。从上到下目标是：槽的热区、节点正文和缩放手柄、连线、组、空白。点空白取消选中。点已选中的文本节点第二次，进入文字编辑，而不是又拖一次。

## 7. 进度怎么呈现

进度是节点上的状态片，加上一条不模态的任务条。禁止用 `window.alert`、`window.confirm` 或整页遮罩来表示排队、运行、成功或失败。遮罩一盖上，平移和「离开再回来」都无从谈起。

点击运行之后，目标时序是：

1. 100 毫秒内（P10）按钮从「运行此节点」变成「取消」，节点主句变成「正在交给本机队列」。此阶段还不知道队列位置。
2. 若本地名额被占用，主句改为「前面还有 N 个本地任务」。这是排队，不是运行。已用时不要从点击起装成生成耗时。
3. 真正开始生成，主句改为「正在生成」，并显示已用时，格式是 `m:ss`。超过一小时用 `h:mm:ss`。
4. 执行器若给出步骤，显示「正在生成（2/4）」这种句子，步骤名用执行器给的人话。执行器没给人话，就只显示步骤数字，不要发明「正在采样」这类 ComfyUI 内部词。
5. 执行器若给出比例，并且标明来源是执行器，才显示百分数，取整到 1%。比例倒退时允许数字变小，不要为了好看卡住不降。
6. 成功：进度片收起，结果按第 8 节出现。任务条里留一行「已完成」，目标 5 秒后收起，节点本身不靠这行才算成功。
7. 失败：进度片换成失败主句，直到用户重试、关闭这条失败或撤销。任务条可以再提一句，但不能是失败的唯一落点。

不定进度的视觉是重复循环，不是从 0 爬到 90 然后停住。循环动画遵守 P23 和 P24。减少动态效果时，不定进度改成静止的省略号或「进行中」字样，主句仍在。

用户可以在生成时平移、缩放、改别的节点、甚至把这个节点拖到视口外。状态跟着节点走，不跟着视口中心走。把节点拖出视口再拖回来，主句和已用时还在，已用时不从头计数。

选中部分运行时，每个节点走自己的时序。汇总句「{total} 个里有 {failed} 个失败」出现在任务条，不替代节点主句。还有节点在排队时，汇总句是「正在运行选中的 {total} 个，{done} 个已有结果」。`done` 含成功和失败，避免用户以为失败的那个还在跑。

图生视频的进度用同一套字段。不要因为视频更久，就改成另一套对话框。视频节点额外始终显示已知时长；时长未知就显示「时长未知」，不要显示 `0:00` 假装是空片。

## 8. 失败时用户看见什么

失败文案用简体中文，冷静，不责备用户，不用感叹号。主句说发生了什么，次句说现在能做什么。错误码用小号字，可以复制。技术折叠默认关上。

任何失败界面都不得出现：API Key 原文或片段、`KSampler`、`VAE`、采样器步数这类计算节点名字、未翻译的英文堆栈作为唯一主句、本机绝对路径里的用户名作为唯一线索。相对路径可以出现在「找不到媒体文件」的次句里，并且用正斜杠。

| 错误码 | 何时 | 主句 | 次句 | 主动作 |
| --- | --- | --- | --- | --- |
| E_BACKEND_DOWN | 本机后端连不上 | 本机服务没连上 | 生成和打开工程都要等服务恢复。画布上已有的东西先不要假装还在保存。 | 重试连接 |
| E_COMFY_DOWN | 后端在，但代理不到 ComfyUI | 连不上本机 ComfyUI | 可以继续摆节点。运行要等 ComfyUI 恢复。 | 重试连接 |
| E_SLOT_EMPTY | 必填槽是空的，用户按了运行 | 还不能运行，缺「{角色名}」 | 把对应的线接到槽 {index}。这次没有进入队列。 | 焦点送到该槽 |
| E_SLOT_ROLE | 线的角色和槽不符 | 这里要的是{期望角色}，这条线是{实际角色} | 线已经回到原来的位置。 | 无，句子出现在槽旁 |
| E_RUN_FAILED | 执行器报告这次生成失败 | 生成没有完成 | 可以再试一次。错误码 {code}。 | 再试一次 |
| E_CANCELLED | 取消成功，且没有新结果 | 已取消，没有新结果 | 原来的结果还留着。 | 再运行 |
| E_CANCEL_LATE | 取消发出时运行已经成功 | 来不及取消，结果已经完成 | 新结果已经放进这个节点。 | 无 |
| E_CANCEL_UNKNOWN | 超过 P14 仍不知道取消结果 | 取消结果不确定 | 它可能还在队列里。可以刷新状态，或等它自己结束。 | 刷新状态 |
| E_PARTIAL | 选中或多节点有的成功有的失败 | {total} 个里有 {failed} 个失败 | 成功的已经留下。可以只重跑失败的那些。 | 只重跑失败的 |
| E_STALE_RUN | 用户坚持运行一个上游已过期的节点 | 将使用上游现在的结果，那些结果已过期 | 运行不会自动先去更新上游。 | 仍然运行 |
| E_MEDIA_MISSING | 工程里的相对路径对不上文件 | 找不到原来的媒体文件 | 缺的是 {相对路径}。节点先空着，避免裂图。 | 重新生成 |
| E_PREVIEW_PENDING | 视频原片已有，封面或代理还没好 | 正在准备预览 | 原片不会直接放在画布上。可以继续摆别的节点。 | 无 |
| E_KEY_MISSING | 这个能力要云端密钥，但凭据库里没有 | 还没有这个服务的密钥 | 密钥不会写进工程文件。填写之后再运行。 | 去填写密钥 |
| E_KEY_REJECTED | 云端拒绝了密钥。不回显密钥 | 密钥被拒绝 | 检查凭据库里的那一项。界面不会显示密钥本身。 | 去填写密钥 |
| E_UPSTREAM_BUSY | 云端暂时不接受，没有具体厂商报文也可以用这句 | 云端暂时拒绝了请求 | 本机队列没有被占用。可以稍后只重试这一次。 | 稍后重试 |
| E_RESTART | 后端或队列重启，任务库对不上结果 | 本机服务重启过，这个任务的结果不确定 | 它不会继续转圈。可以重新运行。 | 重新运行 |
| E_NOT_WIRED | 能力接口留了位置，但这个能力明确还没做 | 这个能力还没有接入 | 当前仍可以用已经接入的能力。 | 无 |
| E_QUEUE | 本地队列异常，不是正常的「前面还有 N 个」 | 本机队列没有接受这次运行 | 可以查看队列里卡住的那一项，或取消它后再试。 | 查看队列 |

`E_STALE_RUN` 不是默认路径。默认是：节点过期，用户按「运行此节点」，界面直接运行这个节点，并用上游当前结果，同时主句短暂说明「用的是已过期的上游结果」。不要为每次运行弹确认。只有用户显式选择「先跑上游」时，才去跑上游，而且那是另一个动作，不是偷偷自动重跑。

`E_RUN_FAILED` 的技术折叠里可以放执行器返回的短句。若短句里含密钥样的长随机串，界面层直接不放入折叠，主句维持不变。验收时用一把假密钥，值固定写成 `test-key-not-real`。失败之后在界面文本、复制出来的错误、以及工程目录的文件内容里搜索这把假密钥，目标是零次命中。这不是某家云厂商的真实报文，只是一把用来验收的假字符串。

校验失败（缺槽、角色不对）不创建「运行中」任务。用户不该在队列里看见一次自己还没提交的失败。

## 9. 空状态

空状态是设计过的画面，不是没数据时的空白。每一种空状态都有主句、次句和最多两个动作。不要用别人的示例图冒充用户的结果。不要用裂开的图片图标。

| 标识 | 何时 | 主句 | 次句 | 动作 |
| --- | --- | --- | --- | --- |
| no-project | 还没有打开工程 | 还没有工程 | 新建一个，或打开已有文件夹。 | 新建工程、打开工程 |
| empty-canvas | 工程打开了，零个节点 | 画布是空的 | 双击空白处添加节点，或从左侧拖一个文本节点。 | 添加文本节点 |
| node-text-empty | 文本节点没有字 | 还没有文字 | 点进去就可以输入。 | 无 |
| node-image-empty | 图片节点没有结果 | 还没有图片 | 接上输入后运行此节点。运行之前这里保持空白。 | 无 |
| node-video-empty | 视频节点没有结果 | 还没有视频 | 视频会先出现封面和时长，不会直接播原片。 | 无 |
| node-audio-empty | 音频节点没有结果 | 还没有音频 | 接上音频参考或生成之后，才会在这里显示时长。 | 无 |
| variant-empty | 节点还没有变体 | 运行后，结果会出现在这里 | 变体先留在节点里，拖出去才会变成新节点。 | 无 |
| slot-empty | 有序槽还没接线 | 槽 {index} · {角色名} · 空 | 必填槽用实线框，选填槽用虚线框。 | 无 |
| queue-empty | 打开了任务条但没有任务 | 现在没有在跑的任务 | 运行节点之后，进度会出现在这里和节点上。 | 无 |
| comfy-unconfigured | 还没配置本机 ComfyUI 地址 | 还没有连接 ComfyUI | 可以先摆节点。生成要等连接之后。 | 去填写地址 |
| capability-unwired | 能力留了接口但未接入 | 这个能力还没有接入 | 不要把它画成一排可点的灰按钮。 | 无 |
| inspector-none | 有侧栏且没有选中 | 没有选中任何东西 | 选中节点后，这里会出现它的输入和结果。 | 无 |

侧栏还没做的阶段，不要为了填 `inspector-none` 先做一个空侧栏。那时只显示 `empty-canvas` 或节点自己的空占位。搜索如果产品领域没做，就不要出现「无结果」搜索框。缺一个功能，不要用空状态冒充那个功能存在。

空画布的背景、文字和按钮要能看出是同一套界面。阶段 A 就要求：间距用 4 的倍数；同一屏字体家族目标不超过两个，字号目标不超过四个；主按钮有悬停、按下、禁用、焦点四态。禁用必须有旁边的原因句，不能只靠变灰。对比度走 P27。这些是阶段 A 的通过条件，不是视觉阶段的事。本文不指定品牌色和插画。

视频和音频的空状态不播放声音、不转圈占满节点。节点内部保持安静，用户才分得清「没有内容」和「正在生成」。

## 10. 取消

凡是 `submitting`、`queued`、`running` 的任务，都有取消。取消不是撤销。撤销管画布编辑，取消管一次生成。取消不删除节点，不自动改上游。

取消不弹确认框。确认框会破坏 P13 的手感，也会让人在长任务里不敢点。删除节点若能用一步撤销回来，同样不弹模态，状态条写「已删除，撤销」，这句停留目标 5 秒。只有确实不能撤销的破坏，才允许应用内确认，且确认句要写清删掉的是什么。第一版不要用浏览器的 `confirm`。

取消的终态只有三种，界面必须选得和事实一致：

- 还在排队、执行器确认没开始：`cancelled`。主句「已取消，没有新结果」。不把半成品文件显示成结果。
- 已经成功：`cancel-lost-race`。主句「来不及取消，结果已经完成」。结果留下。不要先闪一次失败再变成功。
- 执行器没在 P14 的 10 秒目标内给确定性答复：`unknown-after-restart` 那套句子里的「取消结果不确定」，错误码 `E_CANCEL_UNKNOWN`。禁止继续无限转圈。

本地取消由后端去打断 ComfyUI 队列里的那一次。体验不规定打断用的 HTTP 路径。用户只看终态主句是否和「还有没有新结果」一致。

云端取消分两句，不能混用。执行器明确知道对方接受了取消：用「已取消，没有新结果」。执行器不知道对方支不支持取消：主句用「已停止在这里等待」，次句用「若服务端不支持取消，云端可能仍会完成，本应用不再把那次结果放上画布」。不要写成「已为你取消并退款」这类无法从本机证实的话。第一版若还没有云端适配器，这条云端文案不参加阶段 D 的演示，到阶段 H 才算通过条件。文案现在就写死，避免每个厂商各写一句。

运行选中部分时，节点上的取消只取消那一个节点。任务条上另有「取消这一批」，取消还没成功的那些。已经成功的不被取消动作删掉。

取消之后，下游不因为「什么都没发生」而标成过期。没有新结果，下游的新鲜程度维持原样。

## 11. 长时间任务：离开再回来

长时间指用户不会盯着节点等完的那些运行。图生视频是典型。文生图即使较快，也走同一套恢复，避免两套逻辑。

用户可以做这些事，任务都由本机后端的任务库接着记，不记在某一张浏览器标签的内存里：

- 把节点拖出视口，去改别的节点。
- 切换到别的浏览器标签，过两分钟再回来。
- 刷新页面。
- 关掉浏览器，再打开同一工程。
- 生成过程中后端进程重启。

回来时的目标见 P15 和 P16。具体画面：

- 任务仍在跑：节点主句、已用时、队列位置和离开前一致，已用时按真实流逝增加，不从 0 开始。
- 离开时已经成功：节点上是结果。图片是缩略图。视频是封面加时长，不是原片播放器。不要求用户回到这个节点才「领取」结果。
- 离开时已经失败：失败主句还在，不是空节点。
- 离开期间用户自己改过上游：下游除了任务状态，还有过期徽章。过期徽章不触发自动重跑。
- 后端重启且任务库无法证明仍在跑：主句换成 `E_RESTART`，转圈停止。不要显示一个永远的「正在生成」。

标签页隐藏时，界面不再跑追指针的动画，也不要用隐藏标签把轮询加速成忙等。重新可见后再对齐一次状态，目标 ≤ 1 秒。轮询间隔由执行领域决定。体验要求的是：隐藏期间不靠假百分比假装还在动，可见之后 1 秒目标内说真话。

刷新时若工程还没从后端装回来，先显示加载，不超过 P26 的 5 秒目标。装回来之前不要闪一屏 `empty-canvas`，以免用户以为工程丢了。装回之后若确实零节点，才显示空画布。

任务条在用户离开视口时仍更新节点上的状态。不要做成「只有侧栏开着才收得到完成」。侧栏关掉、节点在视口外，完成后徽章仍会在用户把节点拖回来时已经是完成态，而不是拖回来才开始请求。

## 12. 结果出现时的画面

成功的图片节点：先显示缩略图，淡入遵守 P20。不要先显示一个巨大的原图解码，把画布卡死，再换成小图。节点尺寸不因为出图而推开周围节点。用户想看大图时，在节点内或检视区打开，那个查看器可以关。查看器打开时，画布平移默认不在查看器底下继续吃滚轮。

变体默认进节点内的变体条。一次生成出四张，画布上的节点数仍然加零，不是加四。变体条上能看见数量。当前采用哪一张，有选中态，不只靠颜色。把某一张拖出画布，才新长出一个节点，新手势遵守第 6 节。

成功的视频节点：封面、时长、以及首帧和尾帧若能力提供了就在检视区能看到。画布磁贴上不放播放原片的控件。代理文件没好，走 `E_PREVIEW_PENDING`，封面位置用安静占位，不使用裂图。代理好了之后，播放也只在用户明确打开的查看器里进行，并且播的是代理，不是原片。查看器同一时间目标只播一个视频，避免多路原片解码。

音频节点：未选中时只显示图标和时长，不自动出声。选中之后才允许播放。波形若要画，只在选中且近景时画一张静态波形；拖拽进行中不重算波形。波形做不到便宜，就不要画，用时长代替。不要为了好看在一百个节点上同时画动画波形。

版本：再次运行成功，是一条新版本，不是悄悄盖住旧文件却让用户无法分辨。节点上要有「当前版本」的可见说法，例如「版本 2 / 共 3」。切换版本目标 ≤ 100 毫秒换上对应缩略图或封面，不整页刷新。旧版本仍在变体或版本列表里，直到用户明确丢掉。丢掉若可撤销，走第 10 节的撤销句，不走浏览器确认框。

过期的节点继续显示旧结果，角标「过期」，主句「上游改过，结果可能对不上」。旧结果的透明度不要低到看不清。用户是靠它来决定要不要重跑的。

## 13. 哪些选型会让这些目标做不到

这里不拍板用哪一个库。它只说明：若别的领域选定了下面的做法，本文的预算就不要假装仍能达到。总方案要么换选型，要么公开写明哪一条预算作废。静默作废等于没有验收。

下面这些做法和预算是冲突的：

- 每个节点放一个原生 `video` 播放原片，或在画布磁贴里自动播放。P28 和 P4 一起失败，也违反「画布不直接播原片」。
- 远景和近景都解码原图。一千远夹具的 P5 做不到。应使用远色块、近缩略图，原图只在查看时打开。
- 用会触发布局的 `top` 和 `left` 移动上百个节点，而不是用变换矩阵移动视口或节点。P3 和 P4 在一百节点时通常做不到。这是约束，不是已测结论。
- 在 `pointermove` 上对整份工程做深拷贝快照，并当作撤销记录。拖拽的一步撤销会被做成上百步，主线程也会被占满，P2 和 P32 失败。
- 拖拽过程中把工程写入磁盘、计算大文件哈希或等待 ffmpeg。P32 失败。这些事要放到手势结束之后，并且不要堵着下一次指针事件。
- 连线用会触发布局的宽度动画，或用一张包含全部原图的巨大 SVG，且不做视口裁剪。P4 和 P5 做不到。
- 进度只存在某个节点的弹窗里，或者任务数组只放在前端内存。刷新和离开再回来无法满足 P15、P16。任务库必须在后端。
- 用估计时间驱动百分比。P12 和 P30 失败。没有执行器比例就用不定进度。
- 上游一变就自动跑下游。这违反已定边界，也会让取消和过期徽章失去意义。
- 每次出变体都铺成新节点并自动重排画布。P19 失败，一百节点的帧率预算会被一次生成打穿。
- 把 ComfyUI 的 KSampler、VAE 等计算节点画成用户要连的线。失败文案无法保持成人话，空状态也会变成一张节点编辑器。这首先违反边界，其次让本文的文案表无法使用。
- 用会吞掉滚轮和输入法的全局热键层，且不能按「指针是否在文本节点内」放行。P8 失败。
- 桌面壳的网页视图关闭硬件光栅，或套一层远程绘制。阶段 I 不能沿用同一张预算表还声称通过。要末打开可用的光栅，要末另写一张壳预算并标明未达标的行。
- 第一版就做纯静态页，没有后端任务库。离开再回来和密钥不进工程都做不到。运行形态已经定为浏览器加本机后端。

画布领域若比较之后仍然想选会触发布局的方案，必须先拿二十和一百夹具做一版拖拽，读出叠层数字，再决定。读不出数字就不能宣称满足 P3 和 P4。那个比较属于画布领域，本文不代替它选库。

## 14. 测试策略

现在不写测试代码，不选测试框架，不在仓库里加用例文件。策略规定测什么、用什么夹具、怎样算失败。等对应阶段的界面存在之后，再把同一批用例自动化。

测试分成三条线，加上每阶段的手工演示。三条线都不依赖真实 GPU 出图才能把状态走完。真实出图每条能力只留一条演示，避免验收被模型速度绑架。

### 14.1 画布交互

对象是手势和画面，不是模型。夹具用空、二十、一百、一千远。每条用例记录操作、预算编号、读数、三态结论。

必须覆盖的操作：

- 平移三秒，缩放并检查锚点仍在光标下。
- 拖节点，松手，撤销一次，重做一次。撤销栈里这次拖拽只占一步。
- 框选，状态条出现「已选 N 个」。
- 拖动一组，成员跟手，而不是后跳。
- 从桩拖到合法槽，再拖到非法处松开，线回到起点。
- 文本节点输入中文，组字，上屏，撤销一步。
- 在文本节点内滚轮，画布不缩放。
- 缩到一千远，视口内是色块。开发者工具里没有正在播放的原片。
- 把系统缩放设到 150%，桩的热区仍能点中，空状态不被裁切。
- 打开系统「减少动态效果」，状态变化仍能靠图标和文字看懂。

命中顺序用固定重叠夹具：一个组里有节点，节点上有槽，槽上有连线。同一坐标点下去，选中的应是槽，不是组。这个夹具在阶段 B 提供。

自动化以后可以回放指针轨迹，断言叠层计数和 `data-*`。现在只把属性名定下来，不写回放脚本。

### 14.2 任务状态机

用执行领域提供的假执行器把状态走完。假执行器不调用真 ComfyUI，也不调用云端。它要能按测试意图进入这些情况：立即成功、立即失败、一直运行直到被取消、取消时已经成功、取消后不给答复、本地队列已被占住、刷新后仍在跑、重启后任务库对不上。

下表每一行都是一条用例。预期主句必须和界面一致，不能只断言内部枚举。

| 起点 | 动作 | 终点 | 用户必须看见 |
| --- | --- | --- | --- |
| 无任务 | 编辑上游文本 | 下游过期，无任务 | 「上游改过，结果可能对不上」。没有新的 `taskId` |
| 无任务，槽齐 | 运行此节点 | 提交中 | 「正在交给本机队列」，按钮为取消 |
| 提交中，本地名额被占 | 等队列事实 | 排队 | 「前面还有 N 个本地任务」，无百分比 |
| 排队 | 假执行器开始 | 运行中 | 「正在生成，已用时…」。无比例时无百分号 |
| 运行中 | 假执行器成功 | 成功 | 进度收起，结果或封面在，旧节点不被挤开 |
| 运行中 | 假执行器失败 | 失败 | 「生成没有完成」，错误码可见，节点不空白 |
| 运行中 | 用户取消，执行器确认未开始 | 已取消 | 「已取消，没有新结果」 |
| 运行中 | 用户取消，执行器回报已成功 | 取消晚了 | 「来不及取消，结果已经完成」 |
| 取消中 | 超过 10 秒目标无答复 | 不确定 | 「取消结果不确定」，转圈停止 |
| 运行中 | 刷新页面 | 重新挂上 | 仍是运行中或已经的终态，不会先闪空画布 |
| 运行中 | 重启后端且任务库无此在跑任务 | 不确定 | 「本机服务重启过，这个任务的结果不确定」 |
| 成功 | 只把视口转走再转回 | 仍成功 | 不重新请求一遍才显示结果 |
| 选中三个，一个失败 | 运行选中部分 | 部分失败 | 「3 个里有 1 个失败」。两个节点是成功 |
| 过期 | 什么都不按 | 保持过期 | 不出现提交中 |
| 缺必填槽 | 运行此节点 | 无任务 | 「还不能运行，缺…」。队列长度不变 |

假执行器若做不到其中某一行，状态机线就有缺口。不要用真实模型的偶然失败代替「立即失败」那一行，因为那样无法重复。

### 14.3 配方填槽

配方的文件格式由执行领域定。体验用例只看用户能看见的槽，以及「这次有没有进入队列」。用一份虚构配方即可，不要写成某个云厂商的真实报文。虚构例子足够验收的最小槽是：槽 1 提示词，必填；槽 2 参考图，选填；槽 3 首帧，在图生视频阶段必填；槽 4 尾帧，选填。

必须覆盖：

- 必填槽为空就运行：停留在 `E_SLOT_EMPTY`，焦点到该槽，任务库不增加运行中记录。
- 把提示词线拖进参考图槽：线回弹，主句是 `E_SLOT_ROLE`，槽序号不变。
- 两个参考图槽都有来源时，对调顺序，序号目标 ≤ 50 毫秒更新。用户看见的顺序就是以后要提交的顺序。验收时看界面顺序，不看真实网络报文。
- 选填槽为空：允许运行，空槽仍显示「槽 {index} · {角色名} · 空」，不要消失后让后面的槽改号。空选填槽不占一个假来源。
- 一个节点分出两条边，分别进入两个下游的不同槽。两条边都有角色标签。不要合并成一捆没有名字的线。
- 变体还没拖出节点时，下游槽的来源仍是这个节点，不是某一张看不见的变体。拖出之后，新节点才可以被接进槽。
- 用户可见文本里搜索不到 `KSampler` 和 `VAE`。技术折叠默认内容里也没有这两类词。若执行器的技术短句自带这些词，折叠在展示前滤掉，主句不变。

填槽用例在阶段 C 用静态连线先测角色和顺序。阶段 D 再加上「缺槽不会进入队列」。阶段 F 把首帧、尾帧的必填规则加进来。不要在阶段 C 假装已经会生成。

## 15. 分阶段的本机演示

每个阶段结束都要能在 Windows 本机上演示。下面每阶段至少三条。演示失败时，用户看见的句子必须与文案表一致，不能是未捕获异常的叠层。

视觉最低线从阶段 A 就生效：4 的倍数间距、有限字号、四态按钮、P27 对比度、不用 `alert`。以后每个阶段都重新看一眼有没有退回默认控件。退回了，该阶段不通过，即使功能是对的。

### 阶段 A：工程地基与空画布

这个阶段没有生成，也没有成百个节点。手感体现在打开快、失败说人话、空画面是完整的。

演示 A1。后端已在运行，浏览器打开工程。目标：1 秒内看见 `empty-canvas` 的主句「画布是空的」和次句，以及「添加文本节点」。看不见未样式的系统按钮堆，也看不见假图片。预算 P25。失败时若后端其实没起来，必须落到 A2 的句子，而不是白屏。

演示 A2。先关掉后端再刷新。加载圈在 5 秒目标内换成「本机服务没连上」，主动作「重试连接」。页面上没有浏览器默认的报错叠层。把后端重新打开，按重试，回到 A1 的空画布，而不是要用户手动刷新才行。预算 P26。

演示 A3。只用键盘 Tab。焦点依次到达「新建工程」或当前主按钮，焦点环看得见。在 1280×720 和 Windows 150% 缩放下，空状态主句不被裁切，按钮能点到。打开系统减少动态效果后，画面仍能读，不依赖动画才出现按钮。

演示 A4。打开一个已有但零节点的工程，再打开一个不存在的路径。后者的主句是「本机服务没连上」或一条明确的「打不开这个工程」，二者择一实现，但必须有主句和重试或返回。禁止停在空白。本文不规定打不开工程的另外错误码。若实现选择新建错误码，也要有主句和次句，不能只有英文异常名。

### 阶段 B：画布手感

这个阶段加入平移、缩放、节点、连线、选择、分组、撤销和远近细节。仍然可以没有真实模型。

演示 B1。加载二十夹具。平移、拖一个节点、拖一条连线，各三秒。叠层显示超过 32 毫秒的帧数为 0。拖节点时滞后不超过一帧。松手后撤销，节点回到起点，且撤销栈里这次拖拽只有一步。预算 P2、P3、P18。不通过的表现是节点追指针，或撤销要按许多次才回到起点。

演示 B2。加载一百夹具，重复 B1 的三种手势。目标走 P4。再缩放到一千远夹具，平移三秒，目标走 P5。远景节点是色块加标签，不是模糊的原图。页面上没有正在播放的 `video`。把视口里缩略图数量推过 40 的目标时，边缘节点降成色块，而不是帧率塌掉。预算 P6。

演示 B3。在文本节点里用中文输入法打一句「上游改过」。组字窗口在插入符旁。组字时滚轮不缩放画布。上屏后撤销一次，整句消失，而不是只删掉最后一个字。缩放时，光标下的点留在光标下。预算 P7、P8。失败时用户会看见画布乱跑，或撤销把句子拆碎。

演示 B4。做一个组，里面两个节点。拖动组，成员跟手。框选后状态条出现「已选 N 个」，目标 ≤ 50 毫秒。在 150% 缩放下点连接桩，热区能点中。点重叠夹具的同一点，选中的是槽而不是组。预算 P9。

### 阶段 C：语义图

这个阶段加入角色槽、有序汇合槽、变体条、过期徽章。运行可以还是禁用的，但禁用必须有原因句。禁止用真实自动重跑来「顺便」把生成做了。

演示 C1。文本节点连到一张已有图的图片节点，角色是提示词。断网。在文本里上屏一个新字。目标 ≤ 100 毫秒，图片节点出现「过期」和主句「上游改过，结果可能对不上」。旧图还在。不出现「正在交给本机队列」。网络面板里没有新的生成请求。预算 P17、P19。

演示 C2。一个节点的变体条里放四个结果。画布节点数不增加。把其中一个拖出，跟手预算同 P2。松手在画布上，节点数加一，条里原来的四个还在。松手若仍在条内，节点数不变。展开变体条时，其他节点不移位。预算 P21。

演示 C3。做一个汇合节点，槽 1 提示词必填，槽 2 参考图选填，槽 3 参考图选填。空槽显示序号和角色名。把提示词拖到槽 2，线在 180 毫秒目标内回到原处，主句是「这里要的是参考图，这条线是提示词」。把两张参考图对调，序号跟着变，后面的空槽不改号。用户可见文本没有 `KSampler` 或 `VAE`。预算 P22。

演示 C4。此时若运行按钮存在但还不能执行，按钮禁用，旁边写「还不能运行，生成从下个阶段才接入」或等价人话。不要一点击就抛未捕获异常。过期节点在没人按运行时保持过期。

### 阶段 D：执行器与文生图、图生图

这个阶段接本机 ComfyUI，只通过配方填槽跑文生图和图生图，外加参考图槽。界面仍然不出现计算节点。本地并发是 1。

演示 D1。槽齐的文生图，点击「运行此节点」。100 毫秒目标内主句变为「正在交给本机队列」，按钮变为取消。立刻再运行另一个节点。第二个显示「前面还有 1 个本地任务」，没有百分比，除非这次执行器真的给了 `progressSource=executor`。预算 P10、P11、P12。然后用假执行器走完第 14.2 节的表。假执行器路径必须能演示，不能只在模型碰巧很快时看一眼。

演示 D2。清空提示词槽后按运行。主句「还不能运行，缺「提示词」」，焦点在槽 1，队列里不增加运行中任务。把一条参考图线拖进提示词槽，看见 `E_SLOT_ROLE`。用一份缺槽的虚构配方即可，不需要云端。

演示 D3。用假执行器让任务停在运行中，按取消。200 毫秒目标内主句「正在取消」。分别制造三种终态：已取消、来不及取消、超过 10 秒无答复。三句必须和事实一致。取消时画布仍能平移。预算 P13、P14。

演示 D4。真实或假的运行中，刷新浏览器。不允许先闪「画布是空的」。重新挂上后，状态是运行中或终态。再演示「运行选中部分」三个节点、让其中一个失败：汇总句「3 个里有 1 个失败」，成功的两个有结果，失败的那个主句是「生成没有完成」。成功节点不自动去跑它们的下游。

演示 D5。只留一条真实文生图或图生图：从点击到节点上出现缩略图。这条允许慢，不把模型耗时写进预算。慢的时候用户始终看得到排队或正在生成，而不是无响应。出图后拖动画布，仍要满足当前夹具规模的帧率目标。参考图槽接上一张图再跑一次图生图，槽的角色在界面上仍叫参考图。

### 阶段 E：结果版本、来源、缩略图、工程可拷走

演示 E1。同一次节点再运行成功一次。节点显示新版本，例如「版本 2 / 共 3」这种能看出没有覆盖丢历史的句子。切换回版本 1，缩略图换掉，目标 ≤ 100 毫秒，周围节点不动。变体仍在节点内，除非用户拖出。预算 P19、P20。

演示 E2。一百夹具加上刚生成的缩略图，再做 P4 的平移三秒。出图淡入若正在进行，一开始拖拽就跳到终态，帧率仍要过 P4。不要为了过关把缩略图全部关掉。

演示 E3。把工程目录复制到另一个路径。用正斜杠相对路径打开。图片还在。打开工程文件，里面没有二进制图片，没有 `test-key-not-real`，也没有真实密钥。故意把其中一个媒体文件移走再打开，节点主句「找不到原来的媒体文件」，次句里是相对路径，不是裂图，主动作「重新生成」。

演示 E4。查看大图时滚轮不在底下缩放画布。关上查看器，画布回到原来的缩放和位置。来源若在界面上展示，展示的是角色和上游节点，不是 ComfyUI 类名。

### 阶段 F：一条图生视频

只接一条图生视频。文生视频不在这个阶段演示。

演示 F1。图生视频节点在画布上显示封面和时长。时长未知时显示「时长未知」，不是 `0:00`。DOM 里没有指向原片的 `video` 在播放。`data-playback` 为 `poster`。首帧槽为空时运行，主句「还不能运行，缺「首帧」」。尾帧若是选填，为空仍可运行，空槽文案还在。把提示词拖进首帧槽，看见角色错误主句。

演示 F2。代理或封面还没好时，主句「正在准备预览」。此时对一百夹具做平移，预算 P4 和 P29 仍要过。不要等代理完成后才允许拖画布。

演示 F3。开始一次图生视频后，切换到别的标签两分钟，再回来。目标 ≤ 1 秒，主句是仍在生成且已用时包含离开的那段，或已经是封面结果，或是失败主句。刷新一次，结果与任务库一致，不出现第二段重复的「幽灵任务」。取消这次长任务，终态符合第 10 节三种之一。

演示 F4。用户打开查看器才播放，播的是代理。关掉查看器，声音停止。同时只有一个查看器在播。画布磁贴上没有播放键去播原片。

### 阶段 G：参考音频，以及还没接入的能力

第一刀不到这个阶段就不演示音频。能力接口要留位置，但正式界面不要铺满不能用的按钮。

演示 G1。音频参考作为一条带角色的线，拖拽预算同 P3。把它拖进参考图槽，回弹并显示角色错误，句子里的角色名是「音频参考」和「参考图」。未选中的音频节点不自动出声。

演示 G2。音频节点没有内容时，主句「还没有音频」。有内容时显示时长。拖拽画布期间不重算波形。若没有波形，只有时长，也算通过，不要为了验收临时加一条会卡的动画波形。

演示 G3。在开发用的能力列表里能看见文生视频和对口型，状态是未接入，主句「这个能力还没有接入」。正式工具栏上没有一排可点的灰按钮。点未接入项不产生队列任务，也不出现堆栈。已经接入的图生视频路径仍能走 F1。

### 阶段 H：多厂商、密钥、失败与恢复

演示 H1。选一个需要密钥的云端能力，凭据库为空时按运行。主句「还没有这个服务的密钥」。不发往云端的生成请求。主动作去填写。填写界面不把密钥回显到工程文件。

演示 H2。用假密钥 `test-key-not-real` 让执行器走拒绝路径。主句「密钥被拒绝」。在界面、复制出的错误文本、工程目录里搜索这把假密钥，零次命中。技术折叠要么没有这串字符，要么不存在。这不是厂商真实报文。

演示 H3。云端任务超过 15 秒没有心跳，主句改为「云端还在处理，上次有回应是 N 秒前」，百分比不自己增加。同时有一条本地任务在排队。任务条分成本机和云端，不合成一根进度。造 9 个云端运行明细时，只展开 8 条，其余收成「另有 N 个在运行」。预算 P30、P31。

演示 H4。运行中杀掉后端再打开。能对上的任务恢复成运行中或终态。对不上的变成「本机服务重启过，这个任务的结果不确定」，转圈停止，主动作「重新运行」。预算 P16。部分失败的「只重跑失败的」只提交失败项，成功项不闪回排队。

演示 H5。执行器表示云端不保证取消。用户点取消后，主句「已停止在这里等待」，次句说明云端可能仍会完成，本应用不再接收那次结果。本地那一条的取消仍走第 10 节的三种终态，不要被云端文案带跑。

### 阶段 I：桌面壳（后置）

第一版不做壳。这个阶段没有开始之前，不拿壳的标准卡浏览器版。一旦开始做 Electron 或 Tauri，下面三条是最低线，不能只演示「窗口能打开」。

演示 I1。在壳里重做 B1 和 B2。预算数字仍是 P3、P4、P5。不通过就不能说壳完成。若壳的绘制方式做不到，按第 13 节另写预算并标明哪些行未达标，不能把浏览器版的通过记录抄过来。

演示 I2。壳里开始一次长任务，关掉窗口再打开。恢复语义与第 11 节相同。不允许因为换了壳就只把任务放回前端内存。

演示 I3。重复 H2 的假密钥搜索，范围加上壳的日志文件和用户可见的开发者工具默认输出。零次命中。工程文件仍只有相对路径和参数。

## 16. 因已定边界而放弃的内容

已定边界和「把精美留到最后」是冲突的。本文放弃单独的美化阶段。对比度、四态、空状态和失败人话从阶段 A 起算；跟手和帧率从阶段 B 起算；进度、取消和离开再回来从第一次真生成的阶段 D 起算。

本文放弃把本地并发做成多任务同时占用 ComfyUI。边界规定本地并发为 1。所以不设计「本地两张图同时各跑一半」的进度动画。排队句就是本地忙时的诚实界面。云端并发到阶段 H 才验收，并且不和本地合成一根进度。

本文放弃生成后自动摆开一堆新节点的动效。变体留在节点内，只有拖出才成为节点。因此也没有「自动排版」的动画预算。

本文放弃 ComfyUI 计算节点编辑器上的手感标准。不验收连线 KSampler、不验收工作流往返编辑。配方填槽的手感只针对带角色的有序槽。

本文放弃文生视频、对口型、更多厂商在第一刀里的细进度。它们只保留「这个能力还没有接入」，放到阶段 G 和 H。不给没做的能力写假的百分比文案。

本文放弃桌面壳在第一版的帧率门槛。壳后置到阶段 I。因此也不规定无边框、托盘或系统级文件对话框的精致程度。浏览器加本机后端的预算不因「以后会有壳」而放宽。

本文放弃纯静态页方案下的离线手感。没有后端任务库，第 11 节做不到。运行形态以边界为准。

本文放弃使用 `eval/infinite-canvas-src` 作为模块或实测基线。目录能看到它，README 开头写明该项目已停更。没有运行它，也没有把它的界面当验收原件。

本文不规定云端并发的真实配额，不记载任何厂商的请求或响应。百分比只在执行器给出比例时出现。因此放弃「每个厂商都有一条精确到步骤的进度文案」。没有步骤名称时就显示步骤数字或不定进度。

## 17. 跨领域依赖

产品与信息架构要定节点、边、版本和脏状态的正式名字。体验层的 `freshness=stale` 必须能映射到产品的过期，而不是另外发明一种「脏」。若产品的状态机少了失败可见、取消有终态、过期不自动跑这三件事，本文的演示无法通过。运行此节点、运行下游、运行选中部分这三个动作的名字以产品为准，但三个动作的结果不能并成一个看不出范围的「运行」。变体留在节点内、汇合用有序槽，是本文演示 C2 和 C3 的前提。空状态里「双击空白添加节点」若与产品的创建方式不一致，改空状态次句，不要两套入口互相打架。

画布引擎与交互要选定渲染办法，并保证 P1 到 P9、P18 到 P23 做得到。做不到就换办法，不是要求把预算表改小。远近细节的具体缩放阈值由画布领域定，但一千远必须是色块，画布上不播原片，视口内同时解码的缩略图要有上限。撤销必须是手势级的一步，而不是指针移动级的快照。本文不指定用哪个节点图库。命中顺序若画布领域要调整，必须仍能写出和 B4 一样可重复的重叠夹具。

执行与模型接入要提供：同一套能力接口上的任务记录、本地队列位置、取消的三种终态、可选的执行器进度来源、部分失败时每个节点的独立结果、刷新和重启后的重新挂接。假执行器是状态机测试的前提，不调用真模型和真云端。本文不规定 ComfyUI 的提交路径、历史接口或 WebSocket 字段。那些需要对照本机版本核实，不能写成已经验证的报文。没有进度比例时，执行器就不要填一个估计值。云端不支持取消时，执行器要明确告诉界面「只是停止等待」，以便显示对应次句。

媒体工程与运行形态要提供：工程打得开、后端挂了时界面能知道、缩略图和视频封面或代理的就绪事件、内容哈希媒体、工程内正斜杠相对路径、密钥进系统凭据库而不是工程文件。体验在封面未就绪时显示「正在准备预览」。ffmpeg 命令不在本文。桌面壳的选择后置；一旦选择了，阶段 I 的预算仍要重测。启动方式要让「后端已运行」和「后端没运行」两种演示都能稳定做出来。

任何领域都不要在手势过程中同步做落盘、哈希或转码。这是 P32，属于共同约束。

若映射时产品状态名和本文不同，保留一张对照表放进总方案。不要让界面主句直接显示枚举英文。

## 18. 建议落在哪些阶段

预算表的「生效」列是总表。这里按主题再说一次应该落在哪，避免实现时把主题推到最后。

| 主题 | 建议阶段 | 不要推迟的原因 |
| --- | --- | --- |
| 空状态、焦点环、对比度、四态按钮、后端断开的人话、加载圈超时 | A 工程地基与空画布 | 再晚就会先习惯未样式的默认控件 |
| 输入延迟、拖拽帧率、缩放锚点、输入法、撤销一步、分组跟手、远近色块、开发叠层 | B 画布手感 | 没有叠层，后面的帧率无法记通过 |
| 角色槽、有序槽、错误角色回弹、变体条、过期徽章且不自动跑 | C 语义图 | 生成一接进来，错误槽会直接变成一次真跑 |
| 提交中与排队句、不定进度、取消三终态、刷新挂回任务、部分失败汇总、假执行器用例 | D 文生图与图生图 | 这是第一次真有长时间等待 |
| 缩略图淡入但不挡拖拽、版本可见、媒体缺失人话、工程拷走后仍能看 | E 版本与缩略图 | 出图若先解码原图，B 的帧率会被抵消 |
| 封面、时长、代理未就绪、画布不播原片、长任务离开再回来 | F 一条图生视频 | 视频最容易被做成大图片或原片墙 |
| 音频参考的角色手感、不自动出声、未接入能力的空状态 | G 参考音频与未接入能力 | 防止工具栏堆满不能点的按钮 |
| 密钥不回显、云端心跳真话、本地与云端进度分开、重启后的不确定终态 | H 多厂商与密钥 | 失败恢复若等壳做完再补，中间版本会丢任务 |
| 同一张预算在壳里重测，日志不含密钥 | I 桌面壳，后置 | 壳不是美化阶段，也不提前阻塞第一版 |

阶段 A 到 F 是第一刀能演示的体验路径：先有一张说人话的空画布，再有跟手，再有槽和过期，再有一次诚实的文生图或图生图，再有可拷走的缩略图和版本，最后有一条不播原片的图生视频。G、H 在更多能力进来时立即生效。I 等壳真的开工再启用。

不建议增加的阶段是「统一美化」或「统一补测试」。测试代码可以在某阶段的功能落地后补，但第 14 节的用例和每阶段演示在该阶段结束时就要有人做完并填记录。记录可以是不通过。不可以是空白，也不可以靠把预算数字改小变成通过。
